One short funny line answering a prompt: the excuse a robot vacuum gives
after eating a sock.

`main.py` (Python stdlib only) writes the line to `/output/entry.txt`.
The entry is at most 200 characters, as the bounty requires.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
